## Запуск

Откройте `hw1/experiments.ipynb` в Google Colab, выберите GPU T4
и нажмите «Выполнить все». Ноутбук распакует код, установит недостающие
зависимости и скачает два полных архива. Уже скачанные данные используются повторно.
FM работает на GPU, остальные модели на CPU.

Seed равен 42. Настройки выбираются на validation, финальные модели
обучаются только на train и оцениваются на test. Таблицы и графики сохранены
в ноутбуке.

В Colab данные сохраняются в `/content/recsys_hw1/data`, результаты нового
запуска в `/content/recsys_hw1/results_run`. Пути можно изменить через
`GOODREADS_DATA_DIR` и `RECSYS_RESULTS_DIR`.

Реализации моделей находятся в `hw1/models/`, подготовка данных и оценка
в `hw1/utils/`, подбор параметров в `hw1/experiment.py`, финальная оценка
в `hw1/final_train_only.py`.
