# Данные

Загатин Даниил Ильич.

Используется полный Goodreads Book Graph, Comics & Graphic, detailed reviews.
[Первоисточник](https://cseweb.ucsd.edu/~jmcauley/datasets/goodreads.html).

- [Отзывы](https://mcauleylab.ucsd.edu/public_datasets/gdrive/goodreads/byGenre/goodreads_reviews_comics_graphic.json.gz): 542 338 записей.
- [Метаданные книг](https://mcauleylab.ucsd.edu/public_datasets/gdrive/goodreads/byGenre/goodreads_books_comics_graphic.json.gz): 89 411 записей.

Архивы скачиваются из ноутбука автоматически. Правила очистки и итоговый объём
приведены в `experiments.ipynb`. Данные в репозиторий не включаются.
